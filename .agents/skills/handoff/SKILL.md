name: handoff
description: 現在の会話を、別のエージェントが作業を引き継ぐための文書にまとめる。
argument-hint: "What will the next session be used for?"
disable-model-invocation: true
---

新しいエージェントが作業を続けられるよう、現在の会話を要約した引き継ぎ文書を書く。現在のワークスペースではなく、ユーザーのOSの一時ディレクトリに保存する。

文書に「推奨スキル」の節を設け、次のエージェントがSkillツールで呼び出すべきスキル名を記載する。

他の成果物（仕様書、計画、設計判断記録のADR、課題、コミット、差分）にすでに記録された内容を重複させない。代わりにパスまたはURLで参照する。

APIキー、パスワード、個人を特定できる情報など、機密情報は伏せる。

ユーザーが引数を渡した場合は、次のセッションで重点的に扱う内容の説明として受け取り、それに合わせて文書を調整する。
