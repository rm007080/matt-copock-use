# ウィザード

**ウィザード（wizard）**は、手作業では面倒で、AIに毎回説明し直すのも面倒な作業を、人に順を追って案内するbashスクリプトである。各URLを開き、クリックやコピーの対象を正確に伝え、値を受け取り、必要な場所（`.env`、GitHubのシークレット）に書き込み、各段階で確認し、残りの段階数を示す。外部サービスの設定、1回限りの移行、プロジェクトの状態の切り替えなどを扱う。

快適な利用体験（UX）は、[template.sh](template.sh) ですでに用意されている。段階ごとの進捗、確認を挟む仕組み、複数環境でのURL表示（Linux用WindowsサブシステムのWSLを含む）、入力を表示しない機密値の受け取り、繰り返しても結果が変わらない `.env` の追加・更新、`gh secret`／`gh variable` による書き込み、最後の要約である。**あなたの仕事は、手順の範囲を定めて各段階を書くことだけである。** `STAGES` マーカーより上のライブラリーは、すべてのウィザードで同一にする。その一貫性こそが目的なので、手で編集してはならない。

ウィザードは、既定では一時的なものである。1回の実行用に作成し、作業用の場所または `scripts/` 配下に保存して、作業完了後に削除する。ユーザーがリポジトリに残る再実行可能なセットアップ手順を求めた場合にだけ、コミットする。

## 手順

### 1. 手順の範囲を定める

人が行う必要のある手作業と、その途中で取得する値をすべて洗い出す。何も調べずに尋ねず、先にリポジトリを読む。

- セットアップの場合：`.env`、`.env.example`、`.env.*`、`README`、`docker-compose*`、フレームワークの設定、`.github/workflows/*`（`secrets.*`／`vars.*` の各参照は、ウィザードが用意すべき値である）。
- 移行や切り替えの場合：現在の状態、目標の状態、その間に必要な取り消せない操作。

その後、段階を順番に並べた一覧と、各段階で得られる値をユーザーに示して確認する。ユーザーは追加、削除、並べ替えを行ってよい。

**完了条件：** すべての段階が順番に名付けられ、取得する各値について、(a) 人がどこから取得するか、(b) どこへ書き込むか（`.env`、GitHubのシークレット、両方、どこにも書かない、のいずれか。一部の段階は操作だけである）、(c) 機密情報（入力を隠す）か公開情報か、が分かっている。

### 2. 各段階でたどる操作を整理する

段階ごとに、人がたどる正確な経路を書く。開くURL、そこでの操作、値が表示される場所、値を入れる変数を示す。例：「ダッシュボード → 開発者 → APIキー → テストキーを表示 → コピー」。現在の画面や正確なコマンドが分からない場合は、そう伝えてユーザーに尋ねるか、文書を確認する。存在しないかもしれない手順を作り上げない。

**完了条件：** すべての段階が、事情を知らない人でも従える具体的な指示に結び付いている。

### 3. ウィザードを書く

`template.sh` を対象パスにコピーする。例の段階を置き換え、人が行う手順ごとに1つの `stage` を依存順で書く。ライブラリーの補助関数 `stage`、`say`／`step`、`open_url`、`ask`／`ask_secret`、`write_env`、`set_secret`／`set_var`、`pause`／`confirm` を使う。`TOTAL_STAGES` に、書いた段階数を設定する。

テンプレートの品質基準を守る。値を尋ねる前にURLを開き、機密値には `ask_secret` を使い、保存する値はすべて `write_env` で書き込み、継続的インテグレーション（CI）が実際に必要とする値だけを `set_secret` で設定する。取り消せない操作の前には `confirm` を使う。各 `stage` は画面を消去し、現在の手順だけが見えるようにする。人が必要とする情報がスクロールで消えないよう、1段階は1つの作業に絞る。マーカーより上のライブラリーは変更しない。

### 4. 検証して引き渡す

- `bash -n <script>` を実行し、利用可能なら `shellcheck` も実行する。
- `chmod +x <script>` を実行する。
- 自分で最初から最後まで実行しない。ブラウザーを開き、人の入力を待つためである。代わりに実行せずに処理を追う。手順1の各値が取得され、手順1で決めた場所に保存されること、各 `set_secret` 名がCIの `secrets.*` 参照と完全に一致することを確認する。
- ユーザーに実行方法を伝える。再実行可能なセットアップ手順であればコミットし、READMEからリンクする。次の人がAIに尋ねる代わりにスクリプトを実行できるようにする。
