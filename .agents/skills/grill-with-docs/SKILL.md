Skillツールを2回、"grilling" と "domain-modeling" を指定して呼び出す。

質問の進行は `grilling` に従い、両スキルを合わせた対話全体で原則1問ずつにする。用語の確認やADRの作成提案に回答が必要になった場合は、次に扱う質問の候補に加える。回答待ちの質問には追加せず、回答後に依存関係を見直して次の1問を選ぶ。まとめて尋ねる例外は、ユーザーが明示的に求めた範囲だけに適用する。

用語の矛盾確認、具体例による検討、コードとの照合、用語確定時の記録、ADRの提案条件と文書書式は `domain-modeling` に従う。文書管理に伴う質問も同じ進行に含め、文書への記録はPlan Modeなど実行環境の書き込み制約に従う。
