# トリアージラベル

スキルは5つの標準トリアージ役割で話す。このファイルは、その役割をこのリポジトリの課題トラッカーで使う実際のラベル文字列に対応付ける。

| mattpocock/skills のラベル | このトラッカーのラベル | 意味 |
| -------------------------- | -------------------- | ---- |
| `needs-triage`             | `needs-triage`       | メンテナーによるこの課題の評価が必要 |
| `needs-info`               | `needs-info`         | 報告者からの追加情報を待っている |
| `ready-for-agent`          | `ready-for-agent`    | 完全に仕様化され、AFKエージェントの準備ができている |
| `ready-for-human`          | `ready-for-human`    | 人間による実装が必要 |
| `wontfix`                  | `wontfix`            | 対応しない |

スキルが役割に言及した場合（例: 「AFK対応可能のトリアージラベルを適用」）、この表の対応するラベル文字列を使う。

右側の列を、実際に使う語彙に合わせて編集する。
